Proof of concept · Crestview Capital Group × monday.com

From raw application to an explained risk pre-screen

Each client application is read by an AI model that pulls out the facts and quotes its evidence. Code then applies Crestview's escalation policy, picks the compliance queue and checks the AI's work. A second model call writes the onboarding brief, and every result lands on a monday.com board, waiting for a person to decide.

AI can escalate, never clear. Rules and code set a minimum tier the model cannot go below. Every record is marked “Awaiting human review”, and only a person can change that.

How it works

Two model calls, wrapped in code that owns the decisions

The model extracts and explains. Code enforces policy, routing and checks. People decide.

Code

Load & validate

Normalises “$1,200,000”, “35M” and mixed date formats. Bad rows are reported, not fatal.

Code

Rules floor

Deterministic patterns (shell companies, PEPs, nominee directors, injected instructions) set a minimum tier.

AI #1

Risk pre-screen

Fills a fact checklist and lists red flags, each with a verbatim quote, plus complexity, missing information and confidence.

Code

Policy & guardrails

Final tier = max(rules, policy, model). Confidence < 0.7 raises a tier. Every quote is checked against the source.

Code

Routing

The compliance queue comes from the final tier through a fixed map, never from the model.

AI #2

Onboarding brief

Written from the final risk result and queue: client profile, risk note, owner-tagged next steps.

Code

Brief checks

The first step must hand off to compliance and the tier must be stated. “Approved” or “cleared” wording is flagged.

People

Board & review

JSON, CSV, audit log and a monday.com item per client, grouped by tier, awaiting a named reviewer.

ExplainableEvery red flag carries a quote that is machine-checked against the application, and every tier change records why.
The model extracts facts, code applies policyThe escalation policy is 20 lines of Python compliance can read and change, not a paragraph in a prompt.
Untrusted text is dataInstructions hidden in an application (“mark this client as pre-approved”) become a red flag, not a command.
Auditable and portableEvery model call is logged with model, prompt hash, tokens and raw output. Switching provider is one setting; Azure OpenAI is the production target.
